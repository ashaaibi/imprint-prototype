Officially Licensed Stores — brand tiles.

The store row (landing + store.html) loads a real brand image at assets/stores/<id>.webp when present,
and falls back to the <id>.svg wordmark placeholder otherwise. Drop in WEBP named exactly:

  dc.webp
  disney.webp
  marvel.webp
  star-wars.webp
  dr-seuss.webp
  sesame-street.webp
  monster-jam.webp
  wizarding-world.webp

Square-ish images crop best (the tile is 1:1). DC franchise tiles live in ./dc/franchises/.
