Licensed DC franchise tiles go here.

The "Shop by franchise" row on the DC store (store.html?store=dc) loads these filenames.
Drop in JPGs named exactly (lowercase, hyphenated):

  batman.jpg
  superman.jpg
  wonder-woman.jpg
  the-flash.jpg
  green-lantern.jpg
  justice-league.jpg
  joker-harley.jpg
  batwheels.jpg

Until a file exists, that tile falls back to the wordmark placeholder (assets/stores/dc/<id>.svg).
Square-ish images crop best (the tile is 1:1).
